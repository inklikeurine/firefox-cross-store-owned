    GOG library

    Read from your browser's GOG login. Make sure you are signed in at gog.com in Firefox. GOG has no public library API, so there is nothing else to set up.

    Matching

    Games are matched across stores through IsThereAnyDeal's ID database. An API key is optional — lookups currently work without one — but you can add one from isthereanydeal.com/apps/my.

    Keys you enter here are kept in this extension's local storage in Firefox, unencrypted, and are only ever sent to the service they belong to. Empty a field to forget a key.

      Stored data

      Your two libraries, the IsThereAnyDeal answers and the match tables are kept in Firefox so badges show at once. Clearing them keeps your settings, keys and hidden badges; the next refresh reads everything again.
