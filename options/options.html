Cross-Store Owned

Badges games you already own on the other store. Purple G on Steam for games you own on GOG; blue S on GOG for games you own on Steam.

Site access needed

The extension needs permission to read your libraries from Steam, GOG, and IsThereAnyDeal.

Steam library

GOG library

Read from your browser's GOG login. Make sure you are signed in at gog.com in Firefox. GOG has no public library API, so there is nothing else to configure.

Matching

Games are matched across stores through IsThereAnyDeal's ID database. An API key is optional — lookups currently work without one — but you can add one from isthereanydeal.com/apps/my.

Keys you enter here are kept in this extension's local storage in Firefox, unencrypted, and are only ever sent to the service they belong to. Blank a field and save to forget a key.
